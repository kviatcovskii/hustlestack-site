HUSTLESTACK / SYSTEMS TO CONTENT TO INCOME
01 / PRIMARY-SOURCE BRIEF

Separate facts from assumptions before you create.

Input

One official source, the decision your content must support and the publication date.

1. Capture

Record title, author, date and URL.

2. Extract

List only directly supported facts.

3. Separate

Move interpretation into an assumptions section.

4. Reject

Remove claims the source cannot support.

OUTPUT: source-brief.md
Acceptance gate: every factual sentence can be traced to the source.
02 / EVIDENCE-TO-ASSET MAP

Give one researched idea multiple useful jobs.

Input

A verified source brief and one audience problem.

1. Choose

Select one flagship asset.

2. Derive

Map Reel, carousel, short post and email roles.

3. Connect

Choose one relevant product or free next step.

4. Measure

Assign one behavior metric to each format.

OUTPUT: asset-map.md
Acceptance gate: every format has a different job, not duplicated copy.
03 / PROMPT SYSTEM BUILDER

Replace a clever sentence with a reusable standard.

Required structure

Role, outcome, inputs, constraints, output format, acceptance criteria, rejection conditions and next action.

Inputs

What must be supplied before execution?

Constraints

What must never happen?

Acceptance

How will useful work be recognized?

Failure

When should the run stop?

OUTPUT: prompt-system.md
Acceptance gate: another person can run and review it without guessing.
04 / LANDING PAGE FIVE-PASS

Review the decision before polishing the design.

Behavior

What must the visitor understand and do?

Hierarchy

Does each section answer one buyer question?

Proof

Can every claim be supported?

Direction

Are type, imagery and motion intentional?

Mobile QA

Any clipping, overlap or weak CTA?

OUTPUT: qa-report.md
Acceptance gate: the mobile page communicates one offer and one primary action.
05 / CONTENT REPURPOSING LOOP

Repurpose the insight, not the file.

Reel

Demonstrate the outcome or tension.

Carousel

Teach the sequence or evidence.

Black card

Compress one memorable idea.

Email

Add context, limitation and next decision.

Review after seven days

Compare saves, profile actions, clicks and replies. Continue only the formats that perform the job assigned to them.

OUTPUT: weekly-plan.md
Acceptance gate: no truncated copy, broken emoji or repeated asset.
